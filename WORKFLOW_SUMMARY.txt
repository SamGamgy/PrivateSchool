🚨 SAFETY REMINDERS
─────────────────────────────────────────────────────────────────────────────
  ✅ DO:
    • Always pull before starting work
    • Create feature branches for every change
    • Write descriptive commit messages
    • Test locally before pushing
    • Review git diff before committing
    • Keep commits focused on one task

  ❌ DON'T:
    • Commit directly to main
    • Mix multiple features in one commit
    • Push untested code
    • Use force push without good reason
    • Skip commit messages


📚 USEFUL COMMANDS
─────────────────────────────────────────────────────────────────────────────
  INFORMATION:
    git status                      Show current state
    git log -1                      Show latest commit
    git diff                        Show uncommitted changes
    git branch -a                   List all branches

  CHANGES:
    git add .                       Stage all files
    git add index.html              Stage specific file
    git commit -m "message"         Commit with message
    git push origin main            Push to remote
    git pull origin main            Pull from remote

  UNDO (if mistakes):
    git restore file.txt            Discard changes to file
    git reset --soft HEAD~1         Undo last commit, keep changes
    git revert HEAD                 Undo last commit (safe method)
